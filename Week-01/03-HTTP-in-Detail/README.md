## Objective

The objective of this room was to understand how HTTP works and how clients and web servers communicate using requests and responses.

## What I Learned

In this room, I learned the fundamentals of HTTP and how web browsers communicate with web servers.

I learned about HTTP requests, HTTP responses, request methods, status codes, headers and cookies.

I also learned how HTTP and HTTPS are used in web communication and why understanding HTTP is important for cybersecurity and web security.

## Key Concepts

### HTTP Requests

An HTTP request is sent by a client, such as a web browser, to a web server to request or send information.

### HTTP Responses

The server sends an HTTP response back to the client containing the requested information or the result of the request.

### HTTP Methods

Important HTTP methods include:

- GET
- POST
- PUT
- DELETE

### HTTP Status Codes

HTTP status codes indicate the result of a request.

Examples include:

- `200` — OK
- `301/302` — Redirection
- `400` — Bad Request
- `401` — Unauthorized
- `403` — Forbidden
- `404` — Not Found
- `500` — Internal Server Error

### HTTP Headers

Headers provide additional information about an HTTP request or response.

### Cookies

Cookies can be used by websites to store information and maintain user-related state between requests.

### HTTP vs HTTPS

HTTPS provides encrypted communication between the client and server, making web communication more secure than plain HTTP.

## Key Takeaways

- HTTP is fundamental to understanding how the web works.
- Clients communicate with servers through HTTP requests and responses.
- HTTP methods define the type of operation being performed.
- Status codes provide information about the result of a request.
- Headers contain important metadata.
- Understanding HTTP is essential for web security and cybersecurity.
